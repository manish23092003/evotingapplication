# E-Voting System

A comprehensive, secure, and user-friendly electronic voting platform designed to streamline the election process, from voter registration to real-time result visualization.

## 🌟 Features

- **User Registration**: Seamless registration process for eligible voters.
- **Secure Voting**: Built-in authentication (login) to ensure "one person, one vote."
- **Election Updates**: Live notification panel for deadlines and key election dates.
- **Real-Time Results**: Dynamic charts and data visualization for election outcomes.
- **Responsive Design**: Fully optimized for mobile and desktop viewing with an interactive hamburger menu.
- **Support System**: Integrated helpdesk for voter assistance and feedback collection.

## 🚀 Getting Started

### Prerequisites
To run this application, you only need a modern web browser (Google Chrome, Firefox, Microsoft Edge, etc.).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/manish23092003/evotingapplication.git
   ```
2. Navigate to the project directory:
   ```bash
   cd evotingapplication
   ```
3. Open `home.html` in your browser.

## 📂 Project Structure

- `home.html`: The landing page with notifications and navigation.
- `register.html`: Voter registration form.
- `login.html`: Secure login portal for voting.
- `voting.html`: The digital ballot box.
- `results.html`: Visualization of election data.
- `support.html`: Help and assistance page.
- `voucher.html`: Voting confirmation or voucher generation.
- `genderchart.html`: Demographic analysis of voting data.

## 🛠️ Technology Stack
- **Languages**: HTML5, CSS3, JavaScript
- **Styling**: Vanilla CSS (Premium gradients, glassmorphism-inspired UI)
